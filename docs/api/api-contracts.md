# API contracts (v1)

Status: design accepted 2026-10-24, revised 2026-11-06 (immediate confirmation, several units per booking, services, coupons, VAT, online payment, cancellation requests, broadcasts; ADRs 024–028). **Implemented:** `GET /api/v1/health` (M4) and the branch endpoints API-P1…P4 and API-A1…A3 (M5, spec [0002](../specs/0002-m5-branch-websites.md)), all documented in [openapi.json](./openapi.json). Inventory and pricing API-P5, API-S20…S27, API-S30…S34 (M6), services API-S35…S36 and commercial settings API-A5 (M7-T4), and coupons API-S37…S39 (M7-T5) are also **implemented** and documented in OpenAPI. M8-T3b (2026-11-17) adds the `ServiceInput` object form with the transfer car count to API-P6 and `maxVehicles` with the `PER_VEHICLE` unit to API-S35 and API-S36. M9-T4 adds payment methods to P6, hosted checkout to P7, and the Admin online payment switch to A3. Implementation status for each endpoint is shown below. API-S7 and API-S8 (confirm and decline pending requests) are **retired** and must not be built. Shared rules (content type, errors, pagination, CSRF, headers) are in [rest-api-conventions.md](./rest-api-conventions.md) and [error-model.md](./error-model.md) and are not repeated per endpoint. Endpoint ids (`API-…`) are used in the [traceability matrix](../requirements/scope-traceability-matrix.md).

Legend: **Tx** = runs in one database transaction; **Lock** = takes the room-type inventory lock; **Idem** = requires `Idempotency-Key`; **Audit** = appends an `AuditEvent`.

## Common DTOs

```ts
type Money = { amountMinor: number /* cents */; currency: "USD" };
type Stay = { checkIn: string /* YYYY-MM-DD */; checkOut: string };
type Occupancy = { adults: number /* ≥1 */; children: number /* ≥0 */ };
type NightPrice = { night: string; amount: Money | null; source: "BASE" | "PERIOD" | "MANUAL" | null; label: string | null };
type BookingLineInput = { roomSlug: string; occupancy: Occupancy };           // one unit; repeat for several units
type ServiceKind = "BREAKFAST" | "AIRPORT_TRANSFER";
type ServiceInput = ServiceKind | { kind: ServiceKind; vehicles?: number /* AIRPORT_TRANSFER only, 1–maxVehicles, default 1 */; details?: string /* flight number, arrival time; plain text ≤ 300, no control characters, blank = none */ };   // implemented M8-T3b (Q-82); a bare kind stays valid
type QuoteNight = { night: string; amount: Money; label: string | null };                 // every night is priced when a quote exists
type QuoteLine = { roomSlug: string; roomName: string; accommodationType: "ROOM" | "APARTMENT"; occupancy: Occupancy; nights: QuoteNight[]; accommodation: Money };
type QuoteServiceLine = { kind: ServiceKind; unit: ServicePriceUnit; price: Money /* adult or only price */; childPrice: Money | null; adults: number; children: number; nights: number; adultQuantity: number; childQuantity: number; vehicles: number | null /* M8-T3b: cars for AIRPORT_TRANSFER, null for BREAKFAST */; amount: Money };
type Quote = {                                                                  // M7-T6; only chosen services appear, offers of other services are a UI concern (M10)
  stay: Stay; lines: QuoteLine[]; services: QuoteServiceLine[];
  coupon: { code: string; kind: "PERCENT" | "FIXED"; percentBasisPoints: number | null; amount: Money | null } | null;
  accommodation: Money; servicesTotal: Money; subtotal: Money; discount: Money; taxable: Money;
  vatRateBasisPoints: number; vat: Money; total: Money;                         // VAT is never null (Q-05 amended)
};
type GuestInput = { fullName: string; email: string; phone: string /* E.164 */; country?: string; specialRequests?: string };
type Image = { src: string; alt: string; width: number; height: number };   // ready, rights-confirmed library image
type BranchSummary = { slug: string; name: string; summary: string | null; city: string | null; heroImage: Image | null; onlineBookingEnabled: boolean };
type RoomTypeSummary = { slug: string; name: string; accommodationType: "ROOM" | "APARTMENT"; shortDescription: string; maxAdults: number; maxChildren: number; bedroomCount: number | null; bathroomCount: number | null; heroImage: Image | null; detailUrl: string /* /{branch}/stay/{slug} */ };
type ReservationStatus = "AWAITING_PAYMENT" | "CONFIRMED" | "PAYMENT_FAILED" | "CANCELLED" | "CHECKED_IN" | "CHECKED_OUT" | "NO_SHOW";
type PaymentMethod = "PAY_AT_HOTEL" | "ONLINE"; // M9-T1 renamed the former provider-specific value to ONLINE (ADR 030)
type CancellationRequestDto = { id: string; status: "OPEN" | "APPROVED" | "REJECTED" | "REFUND_PENDING" | "REFUND_FAILED" | "COMPLETED" | "CLOSED"; createdAt: string; decisionReason: string | null };
```

## Staff endpoints

Authentication: staff session cookie. Authorization: listed capability **and** branch access. "Branch" is the reservation's or resource's branch. Lists require `branchId` unless the caller is Admin or the endpoint documents an implicit branch scope.

## Transaction boundaries summary

| Operation | Transaction contents |
| --- | --- |
| Create (P7, S3, S4) | Idempotency check → verification and caps → lock listings (id order) → expire overdue holds → capacity/sold/rates/services → lock coupon → quote → insert reservation, lines, nights, services, redemption → audit → outbox (confirmations only when `CONFIRMED`) |
| Payment callback (P8) | Record event once → reservation `FOR UPDATE` → confirm or fail (late success re-locks listings) → audit → outbox |
| Cancellation decision (S18, S19, S9 paid) | Request and reservation `FOR UPDATE` → decision → (paid) refund requested after commit → `CompleteRefund` under the reservation lock when the gateway answers (the call itself, the refund callback, or the 10 minute lookup; only the current attempt key applies) → release → audit → outbox |
| Transition (S9–S13, S16) | `SELECT … FOR UPDATE` reservation → version check → state machine → update status and `consumesInventory` → audit → outbox |
| Modify stay (S6) **(implemented M8-T9)** | Unlocked read for the listing set → lock old and new listings (sorted) → reservation `FOR UPDATE` and version check → availability (own units excluded) and prices read under the locks → replace stay, nights and snapshot → change row → audit → outbox, in one transaction |
| Block, unit deactivation (S23, S25, S26) | Lock unit's type → check sold versus new capacity → write → audit |
| Rate, service, coupon, VAT edits (S31–S39, A5) | Write → audit (no inventory lock) |
