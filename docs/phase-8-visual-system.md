# Phase 8 luxury visual system handoff

Status: **Accepted on 2026-09-26**
Completed: 2026-09-26
Scope: the Rivana visual system applied to every public template, plus the Phase 7 review fixes, a light-touch staff login refresh, and a demo seed for local review. Phase 9 owns section reveals, gallery/lightbox motion, and submenu behavior.

## Outcome

The public site now reads as a modern Rivana luxury property rather than a functional baseline:

- **Brand:** the approved sun-crest logo replaces the text wordmark in the header, footer, mobile menu, not-found page, and staff login. The crest's sun-ray arc is repeated as a quiet SVG watermark on plum surfaces.
- **Header:** transparent over photography with a soft scrim. With JavaScript it becomes a fixed, warm translucent bar with the light-background logo after scrolling. Without JavaScript it scrolls away and stays readable.
- **Heroes:** a full-screen home hero with display type at up to 104px, a gold eyebrow rule, a scroll cue, and a brush edge into the canvas. Room and facility heroes are full-bleed only when the photo is at least 1400px wide. Otherwise the photo sits beside the title at its natural resolution inside an offset gold frame.
- **Editorial composition:** a heading-beside-lead introduction, numbered room cards in a staggered three-column rhythm, photographic facility tiles on a plum band, framed image/text splits, large stat numerals between hairlines, and a mosaic gallery.
- **Detail pages:** a breadcrumb, a sticky "At a glance" panel with facts and the inert Book Now control, a ruled feature list, and related amenities or rooms.
- **Contact:** icon-led address/phone/email rows, a framed map with a branded fallback, and an enquiry form in a floating card on plum.
- **Footer:** the logo, the brand tagline set as a display statement, "Plan your stay", then Explore/Visit/Contact columns.
- **Mobile menu:** a full-screen plum panel with large numbered display links and contact shortcuts. It is still the native `<details>` disclosure, so it works without JavaScript.
- **Staff login:** a split layout with a plum brand panel. The form and its behaviour are unchanged.

Content remains CMS-managed, and nothing in this phase adds prices, availability, or a booking destination.

## Phase 7 review fixes

See [phase-7-public-site.md](./phase-7-public-site.md#review-findings-2026-09-26). In short, the Phase 7 stylesheet rewrite had deleted the `.brand-mark` rules, so the admin wordmark rendered as "RivanaResidence". Those rules are restored. The approved logo is now used. Narrow room photos are no longer stretched. `gold-600` meets AA on the canvas. The fixture copy now follows the legacy site.

## Visual regression

`tests/e2e/visual.spec.ts` compares each template's opening screen at 1440×900 and Pixel 7 against the baselines in `tests/e2e/visual.spec.ts-snapshots/`, allowing a 2% pixel difference. It runs after the public suites and before the promotion suite, so no pop-up appears. The baselines are macOS (`darwin`) renders. CI on Linux needs its own baselines.

## Local review setup

`npm run db:seed:demo` publishes the same demo site the browser tests use (3 rooms, 2 facilities, Home/About/Contact, settings, and 21 imported reference images) into `DATABASE_URL`, with media written to `MEDIA_STORAGE_ROOT`. It first adds any missing default page sections, and it refuses to run if rooms, facilities, or media already exist. After seeding, delete `.next/cache/fetch-cache` (and `.next/dev/cache/fetch-cache` in development) and reload the site.

The local `rivana` database has been seeded this way, and `.env` now points `MEDIA_STORAGE_ROOT` at `../rivana-media`, outside the repository.

## Known limits and next work

- **Content approval (acceptance blocker):** the phone number, email, and room facts are test values. Stats (28 rooms, 30 team members, 24/7 reception) come from the legacy site and need confirming. The reference photographs still need per-image rights confirmation (Phase 6) before production publishing.
- **Photography:** a wider home hero original and higher-resolution room photos are the biggest remaining quality gains. See the image review above.
- **Logo:** the lockup is a 500×300 PNG. A vector (SVG) master from the brand designer would keep it crisp at every size.
- **Linux baselines:** CI on Linux will need its own visual baselines.
- **Phase 9:** section reveals, the gallery lightbox and swipe, the header transition polish, and the desktop submenu.
