# M4 verification: backend foundations and branch data ownership

Date: 2026-11-06. Spec: [0001](../specs/0001-m4-backend-foundations.md). Brief: [M4](../delivery/milestones/m4-backend-foundations.md).

**Verdict: PASS.** All 11 acceptance criteria are met, and every specced surface exists. AC-3 is proven by the brief's unit tests over `Request` objects, because M4 ships no staff mutation endpoint to call over HTTP.

## How it was run

- **Database:** a fresh copy of the local development database `rivana` (`createdb -T rivana rivana_m4_verify_test`). It was taken after a `pg_dump` backup, then migrated with `prisma migrate deploy`. The development database itself was not changed.
- **App:** the production build (`next start`), run against that copy on `127.0.0.1:3200`. A second instance on port 3201 pointed at an unreachable database (`127.0.0.1:1`) for the failure path.
- **Accounts:** created with the real staff CLI (`npm run staff -- create … --role RECEPTIONIST --branch new-cairo`, `… --role MANAGER`, then `assign-branch`).
- **Browser:** headless Chromium (Playwright) at 1280×800 and 390×844.

## Finding during verification (environment, not code)

The first server run answered `503` on every health call. `/debug` traced it to Postgres.app: its log said "node is not allowed to connect without a password … Configure app permissions in Postgres.app settings". A server started with `nohup`, detached from the session, cannot get the permission dialog. The same build, started attached, answered `200` in 3 ms. No code changed. That run did show the failure path working live: `503` problem+json after the 2 second probe timeout, with nothing leaked.

## For /check review

- An unsupported method on an API route returns Next's built-in `405` without a problem body. That is acceptable, because the error model does not cover 405. Note it if API clients need a uniform body later.
- Media and other database reads in a server that cannot reach Postgres hang until the driver gives up, because only health has a timeout. This behavior predates M4.
