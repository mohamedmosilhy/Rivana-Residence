## Major

### 🟠 External snapshots accept services and coupons, `src/domain/reservations/reservation.ts:277`

**Problem**: The snapshot validator recomputes service and coupon amounts for every source. For `EXTERNAL`, it never requires empty service lines and a null coupon value, contrary to Q-76 in `docs/requirements/assumptions-and-open-questions.md:70`.

**Why it matters**: A complete external booking with one 100-cent manual night, a 10-cent breakfast, a 10% coupon, and 15% VAT passes `validateReservationCreation`, with a total of 114 cents. This was reproduced through the public domain API with Node and the tsx loader. The arithmetic is internally consistent, but the snapshot violates the approved external pricing rule, so later writers cannot rely on this validator to enforce it. The existing tests cover unpriced external bookings but miss this priced case.

**Suggested fix**: Reject services or any coupon value for an external snapshot, while preserving valid priced and wholly unpriced external bookings. Add regression coverage for both prohibited inputs, including a service or coupon whose totals are otherwise correct.

### 🟠 Consent version policy is absent, `src/domain/guests/index.ts:1`

**Problem**: Q-73 assigns the server consent version constants to M8-T2/T7, but the guest module has no privacy notice version, marketing wording version, or pure version check. Only HTTP enforcement was deferred by the approved T-VAL clarification.

**Why it matters**: The later booking use case has no approved domain value against which to check a submitted stale or mismatched consent version. Leaving this absent makes the T2 domain surface incomplete and invites later duplication or trusting a request supplied version. This is a missing pure policy, not a request to implement consent persistence or an endpoint in T2.

**Suggested fix**: Add explicitly provisional server version constants and a pure validator with focused tests for matching and mismatched values. Keep HTTP mapping, opt-in persistence, and audit in their scheduled tasks. Do not imply that placeholder version values are approved legal text.
