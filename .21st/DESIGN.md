# Rivana Residence design context

The production direction is modern luxury hospitality: strong editorial typography, deep plum fields, restrained gold accents, warm canvas, square imagery, generous whitespace, and minimal motion.

Public surfaces use Marcellus for display text and Jost for body/UI. Admin surfaces use the same tokens with quieter panels, visible borders, small radii, and task-oriented density.

All work must preserve semantic landmarks, keyboard behavior, visible focus, reduced-motion support, 20px minimum mobile gutters, and the approved 1200px content container. Do not introduce fake booking data, generic glass effects, excessive cards, or large decorative gradients.
